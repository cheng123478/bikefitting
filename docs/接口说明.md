# Aries API 接口说明文档

## 基础信息

### 基础URL
```
开发环境: http://localhost:9200/aries
生产环境: https://your-domain.com/aries
```

### 请求头说明
```
Authorization: Bearer <access_token>  # 认证令牌（除白名单接口外必需）
User-Agent: <客户端User-Agent字符串>   # 设备标识
Content-Type: application/json         # 请求体格式
```

### 响应格式
```json
{
  "code": 200,
  "message": "操作成功",
  "data": {}
}
```

### 响应状态码

| 状态码 | 说明 |
|--------|------|
| 200 | 请求成功 |
| 401 | 未授权/Token无效/Token过期 |
| 403 | 无权限访问 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |

## 认证接口

### 1.1 密码登录

**接口说明**: 使用手机号和密码登录

**请求方式**: `POST`

**接口路径**: `/user/login`

**是否需要认证**: 否

**请求参数**:
```json
{
  "phone": "13800138000",
  "password": "RSA加密后的密码字符串"
}
```

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| phone | String | 是 | 手机号 |
| password | String | 是 | 密码（RSA加密，Base64编码） |

**响应示例**:
```json
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "accessToken": "Bearer eyJhbGciOiJSUzI1NiIsInR5cCI6IkpXVCJ9...",
    "refreshToken": "Bearer eyJhbGciOiJSUzI1NiIsInR5cCI6IkpXVCJ9...",
    "profile": {
      "id": "1234567890123456789",
      "phone": "13800138000",
      "name": "骑士8000",
      "introduction": "个性签名",
      "avatar": "/resource/avatar/xxx.jpg",
      "birthday": "1990-01-01",
      "gender": 1,
      "location": "北京市"
    }
  }
}
```

**错误响应**:
```json
{
  "code": 401,
  "message": "密码错误"
}
```

**注意事项**:
1. 密码必须使用RSA公钥加密后再传输
2. 连续登录失败5次账号将被锁定
3. 账号锁定后第二天自动解锁
4. 首次登录时若用户不存在会自动创建

### 1.2 短信验证码登录

**接口说明**: 使用手机号和短信验证码登录

**请求方式**: `POST`

**接口路径**: `/user/login/sms`

**是否需要认证**: 否

**请求参数**:
```json
{
  "phone": "13800138000",
  "code": "123456"
}
```

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| phone | String | 是 | 手机号 |
| code | String | 是 | 短信验证码（6位数字） |

**响应示例**: 同密码登录接口

**注意事项**:
1. 需先调用发送短信接口获取验证码
2. 验证码有效期为5分钟
3. 验证码验证后立即失效（一次性使用）
4. 首次登录时若用户不存在会自动创建

---

### 1.3 刷新Token

**接口说明**: 使用Refresh Token获取新的Access Token

**请求方式**: `POST`

**接口路径**: `/user/refresh`

**是否需要认证**: 否

**请求头**:
```
Authorization: Bearer <refresh_token>
User-Agent: <与登录时相同的User-Agent>
```

**请求参数**: 无（从请求头获取）

**响应示例**: 同登录接口

**错误响应**:
```json
{
  "code": 401,
  "message": "身份验证已过期，请重新登录"
}
```

**注意事项**:
1. Access Token有效期2小时，Refresh Token有效期7天
2. 当Access Token过期时，前端应自动调用此接口
3. User-Agent必须与登录时一致
4. Refresh Token也会返回新的Refresh Token，前端需要更新

---

### 1.4 退出登录

**接口说明**: 用户退出登录

**请求方式**: `POST`

**接口路径**: `/user/logout`

**是否需要认证**: 是

**请求参数**: 无

**响应示例**:
```json
{
  "code": 200,
  "message": "退出成功"
}
```

**注意事项**:
1. 前端需要清除本地存储的Token
2. 服务器会清除Redis中的会话信息

**请求方式**: `POST`

**接口路径**: `/user/password/add/code`

**是否需要认证**: 是

**请求参数**:
```json
{
  "code": "123456",
  "password": "RSA加密后的新密码字符串"
}
```

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| code | String | 是 | 短信验证码（发送到用户手机） |
| password | String | 是 | 新密码（RSA加密） |

**响应示例**:
```json
{
  "code": 200,
  "message": "密码设置成功"
}
```

**错误响应**:

**注意事项**:
1. 密码必须使用RSA加密后传输

3. 设置成功后可以使用密码登录

### 2.5 修改用户信息

**接口说明**: 修改用户基本信息（昵称、个性签名、生日、性别、地址等）

**请求方式**: `PUT`

**接口路径**: `/user/edit`

**是否需要认证**: 是

**请求参数**:
```json
{
  "name": "新昵称",
  "introduction": "这是我的个性签名",
  "birthday": "1990-01-01",
  "gender": 1,
  "location": "北京市朝阳区"
}
```

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| name | String | 否 | 昵称（最长50字符） |
| introduction | String | 否 | 个性签名（最长100字符） |
| birthday | String | 否 | 生日（格式：yyyy-MM-dd，必须小于当前日期） |
| gender | Integer | 否 | 性别（0-未知，1-男，2-女） |
| location | String | 否 | 地址（最长100字符） |

**响应示例**:
```json
{
  "code": 200,
  "message": "用户信息修改成功",
  "data": null
}
```

**注意事项**:
1. 所有字段都是可选的，只修改传入的字段
2. 生日不能晚于当前日期
3. 参数校验错误会返回400状态码

## 错误码说明

### 通用错误码

| 错误码 | 说明 | 解决方案 |
|--------|------|----------|
| 200 | 请求成功 | - |
| 400 | 请求参数错误 | 检查请求参数格式和必填项 |
| 401 | 未授权 | 检查Token是否有效，是否过期 |
| 403 | 无权限访问 | 检查用户权限 |
| 404 | 资源不存在 | 检查请求路径 |
| 500 | 服务器内部错误 | 联系系统管理员 |

### 业务错误码

| 错误码 | 说明 | 解决方案 |
|--------|------|----------|
| 1001 | 未获取到客户令牌 | 请求头携带Authorization |
| 1002 | 令牌解析失败 | 检查Token格式 |
| 1003 | 令牌已过期 | 调用刷新接口或重新登录 |
| 1004 | 令牌无效 | 重新登录 |
| 1005 | 会话已失效 | 重新登录 |
| 2001 | 手机号不正确 | 检查手机号格式 |
| 2002 | 短信验证码错误 | 重新获取验证码 |
| 2003 | 旧密码错误 | 确认旧密码是否正确 |
| 2004 | 该手机号已被使用 | 使用其他手机号 |
| 2005 | 账户已被锁定 | 等待第二天自动解锁 |
| 3001 | 上传头像失败 | 检查文件格式和大小 |
| 9999 | 系统异常 | 联系系统管理员 |

## 接口调用示例

### 1. 完整登录流程

```javascript
// 步骤1: 发送短信验证码
POST /aries/sms/send
{
  "phone": "13800138000"
}
// 响应: {"code": 200, "message": "发送成功", "data": "123456"}

// 步骤2: 使用验证码登录
POST /aries/user/login/sms
{
  "phone": "13800138000",
  "code": "123456"
}
// 响应: 获取 accessToken 和 refreshToken

// 步骤3: 存储Token
localStorage.setItem('accessToken', response.data.accessToken);
localStorage.setItem('refreshToken', response.data.refreshToken);
```

### 2. 带认证的请求

```javascript
// 设置请求拦截器（Vue示例）
axios.interceptors.request.use(config => {
  const token = localStorage.getItem('accessToken');
  if (token) {
    config.headers.Authorization = `Bearer ${token}`;
  }
  return config;
});

// 修改用户信息
PUT /aries/user/edit
Authorization: Bearer <access_token>
{
  "name": "新昵称"
}
```

### 3. Token刷新流程

```javascript
// 设置响应拦截器处理401
axios.interceptors.response.use(
  response => response,
  async error => {
    const originalRequest = error.config;
    if (error.response.status === 401 && !originalRequest._retry) {
      originalRequest._retry = true;
      try {
        const refreshToken = localStorage.getItem('refreshToken');
        const response = await axios.post('/aries/user/refresh', null, {
          headers: {
            'Authorization': `Bearer ${refreshToken}`,
            'User-Agent': navigator.userAgent
          }
        });
        // 更新Token
        localStorage.setItem('accessToken', response.data.data.accessToken);
        localStorage.setItem('refreshToken', response.data.data.refreshToken);
        // 重试原请求
        originalRequest.headers.Authorization = `Bearer ${response.data.data.accessToken}`;
        return axios(originalRequest);
      } catch (refreshError) {
        // 刷新失败，跳转登录页
        localStorage.clear();
        window.location.href = '/login';
      }
    }
    return Promise.reject(error);
  }
);
```

## 开发注意事项

### 1. RSA加密示例（前端）

```javascript
// 使用 JSEncrypt 库进行RSA加密
import JSEncrypt from 'jsencrypt';

// 公钥（从后端获取）
const PUBLIC_KEY = '-----BEGIN PUBLIC KEY-----\n...\n-----END PUBLIC KEY-----';

// 加密函数
function rsaEncrypt(text) {
  const encrypt = new JSEncrypt();
  encrypt.setPublicKey(PUBLIC_KEY);
  return encrypt.encrypt(text);
}

// 使用示例
const encryptedPassword = rsaEncrypt('mypassword');
```

### 2. Token管理建议

```javascript
// Token存储
const tokenStorage = {
  setTokens(accessToken, refreshToken) {
    localStorage.setItem('accessToken', accessToken);
    localStorage.setItem('refreshToken', refreshToken);
    localStorage.setItem('tokenExpireTime', Date.now() + 2 * 60 * 60 * 1000); // 2小时
  },
  
  getAccessToken() {
    return localStorage.getItem('accessToken');
  },
  
  getRefreshToken() {
    return localStorage.getItem('refreshToken');
  },
  
  isTokenExpired() {
    const expireTime = localStorage.getItem('tokenExpireTime');
    return !expireTime || Date.now() > parseInt(expireTime);
  },
  
  clearTokens() {
    localStorage.removeItem('accessToken');
    localStorage.removeItem('refreshToken');
    localStorage.removeItem('tokenExpireTime');
  }
};
```

### 3. 请求拦截器配置

```javascript
// Axios拦截器
axios.interceptors.request.use(config => {
  // 添加Token
  const token = tokenStorage.getAccessToken();
  if (token) {
    config.headers.Authorization = `Bearer ${token}`;
  }
  
  // 添加User-Agent
  config.headers['User-Agent'] = navigator.userAgent;
  
  return config;
}, error => {
  return Promise.reject(error);
});
```
